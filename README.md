# audio

because Apple Music is trash and i need something lightweight to listen to my music folder.

press play to shuffle through `~/Music`. use media keys, the `audio` cli, or the tiny menu-bar control. it replaces Apple Music for local playback and keeps it closed.

## install

```sh
git clone --depth 1 https://github.com/zxrl/audio.git && ./audio/install.sh
```
